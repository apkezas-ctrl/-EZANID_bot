# EZA File Converter Bot

Telegram polling bot for file conversion.

Features:
- PDF → PNG images
- Image → PDF
- Screenshot → PDF
- Multiple Images → one PDF
- Balance / jobs / settings / support
- `/demo` creates a clearly marked SAMPLE/DEMO document for UI testing

Render Background Worker:
- Build: `pip install -r requirements.txt`
- Start: `python main.py`
- Environment: `BOT_TOKEN` = your Telegram BotFather token

Never put the real BOT_TOKEN in GitHub.

Safety:
The demo generator intentionally does not reproduce government IDs,
official branding, official verification QR codes, or authentic credentials.
