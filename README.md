# EZA File Converter Bot — Render Free Webhook

Render Web Service:
Build Command: pip install -r requirements.txt
Start Command: python main.py

Environment Variable:
BOT_TOKEN = your BotFather token

Optional if needed:
PYTHON_VERSION = 3.13.5

This version uses Telegram webhook and opens Render's PORT, so it is intended for a Web Service rather than a Background Worker.

Never put BOT_TOKEN in GitHub or send it in chat.
