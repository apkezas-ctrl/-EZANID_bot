# EZA Render Print Bot — Safe Generic Version

This is a Render Web Service / Telegram webhook bot.

Build Command:
pip install -r requirements.txt

Start Command:
python main.py

Environment Variable:
BOT_TOKEN = your BotFather token

Render automatically supplies:
PORT
RENDER_EXTERNAL_URL

Features:
- Print from PDF
- Print from Screenshot
- Bulk Screenshot
- Group to A4
- JPEG / PNG / PDF output
- A4 Fit
- Black & White
- Mirror
- Balance / Top Up / My Jobs / Refer / Dashboard / Settings / Support

This version performs generic document/image processing. It does not create, modify, or generate official identity documents, official verification QR codes, or government ID cards.
Never put BOT_TOKEN in GitHub or send it in chat.
